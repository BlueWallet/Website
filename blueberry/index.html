Features

Compact block filters

Sync connects to Bitcoin peer-to-peer network directly. There is no server that can track your balance.

Broadcast via Tor

Outgoing transactions are broadcast through a minimalistic Tor implemention built into the app.

Private send

Private send goes through RocketX. Normal send does not.

Coin control

Advanced UTXO management, labeling, selecting, inspection

Labels sync

Labels for transactions, addresses and UTXOs are backed up and synced with e2e encryption to all your devices.
