---
title: How do I connect a hardware wallet?
categories: [docs]
---

Import it as watch-only using the device’s public key, build the transaction in BlueWallet, sign the PSBT on the hardware wallet (QR or file), then bring the signed transaction back to broadcast. This works with PSBT-compatible hardware wallets. See [Watch-only](/watch-only/) and [Sign a transaction offline](/docs/sign-offline/).
