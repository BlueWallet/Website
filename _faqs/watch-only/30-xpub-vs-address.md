---
title: Should I import an xpub, ypub, zpub, or a single address?
categories: [watch-only]
---

Use an **extended public key** (xpub/ypub/zpub) to generate new receiving addresses. Import a **single address** only when you want to watch that one output. zpub is the usual pair for a Native SegWit wallet. You can copy it from [Wallet details](/docs/wallet-details/) → **Show Wallet XPUB** on the device that holds the keys.
