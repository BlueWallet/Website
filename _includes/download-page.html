BlueWallet

This is the official download page for BlueWallet — a self-custody Bitcoin wallet. Your keys stay on your device. Get it only from the sources listed below.

Install paths

Every platform BlueWallet ships on today. Nothing else is official.

iOS

Recommended for iPhone and iPad. Updates through the App Store.

  • App Store — package io.bluewallet.bluewallet

Android

Google Play is the default. Sideload the APK from GitHub if you need to install offline or without Play Services.

  • Google Play — package io.bluewallet.bluewallet
  • GitHub releases — latest .apk (and .apk.sig signature file)

Desktop (macOS)

BlueWallet desktop is macOS only. There is no official Windows or Linux build.

  • Mac App Store
  • GitHub releases — .dmg when published
  • Homebrew — brew install --cask bluewallet

Verify before you install

Self-custody means you are responsible for what runs on your device. Check the source.

Phishing alert — fake “update” sites

In June 2026, scammers ran a fake site at update-bluewallet.com that looked like BlueWallet. It auto-downloaded a file called BlueWallet Installer.applescript and told victims to open it in macOS Script Editor and press Run. That was malware — not BlueWallet. BlueWallet was not hacked; the attackers copied our name and branding.

Never run Script Editor or AppleScript “installers” for BlueWallet. Real BlueWallet installs through the App Store, Google Play, a .dmg from GitHub, or Homebrew — not AppleScript.

Trusted sources only

Download BlueWallet only from:

  • bluewallet.io — this website
  • apps.apple.com — App Store / Mac App Store
  • play.google.com — Google Play (io.bluewallet.bluewallet)
  • github.com/BlueWallet — official GitHub org (releases)

Do not trust lookalike domains, sponsored search ads, DMs, Telegram links, or “update” pages. If the URL is not one of the above, walk away.

Verify APK and GitHub releases

Android APKs and iOS IPAs are published on GitHub releases. Each release may include a .sig signature file alongside the binary.

Before sideloading an APK, confirm the package name is io.bluewallet.bluewallet and that you downloaded from the official BlueWallet/BlueWallet repository — not a fork or mirror.

BlueWallet is open source (GitHub), but builds are not verified as reproducible on WalletScrutiny. You can review the source and compare checksums, but independent reproducible-build verification is not available yet.

PGP key

Verify signed messages and release announcements from BlueWallet maintainers. Key fingerprint and download: /pgp/ · bluewallet-key.txt
